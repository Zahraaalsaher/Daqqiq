# دقّق | DAQQIQ

**افهم عقد عملك قبل التوقيع** — نموذج أولي تعليمي لمراجعة بنود محددة في **عقود العمل بالقطاع الخاص السعودي**.

**رابط التطبيق الرسمي (بعد اعتماد التحديثات):** https://daqqiq-sa.streamlit.app  
**رابط الاختبار الحالي:** https://daqqiq-ocr-test.streamlit.app  
**المستودع:** https://github.com/Zahraaalsaher/Daqqiq

> **تنبيه:** النموذج أداة مساعدة للفهم والمراجعة الأولية، وليس استشارة قانونية أو حكمًا نهائيًا على صحة العقد. يُرجى التحقق من النص النظامي الساري والاستثناءات والسياق لدى جهة مختصة.

## نطاق المشروع

يركز النموذج على أربعة موضوعات فقط في عقود العمل السعودية:

1. **فترة التجربة** — المادة 53.
2. **ساعات العمل** — المواد 98–100.
3. **الإجازة السنوية** — المادة 109.
4. **الراتب والبدلات ووضوح بياناتها** — مع الإشارة إلى المادة 52.

لا يراجع النموذج عقود الإيجار أو الشراكة أو جميع بنود عقد العمل، ولا يقدم رأيًا قانونيًا شاملًا.

## ما نُفّذ بالفعل

- رفع عقد بصيغة PDF واستخراج النص باستخدام PyMuPDF.
- محاولة قراءة الصفحات المصورة باستخدام OCR بالعربية والإنجليزية.
- فحص أولي قائم على قواعد وأنماط نصية للبنود الأربعة.
- التمييز بين **تعارض محتمل**، **تحتاج مراجعة**، **معلومات ناقصة**، و**لم يُرصد تجاوز** بحسب النص المتاح.
- عرض المقطع المستخرج، وتفسير مبسط، وتوصية، ورقم المادة النظامية، وروابط مرجعية رسمية للتحقق.
- ملخص لنتائج الفحص، وتقرير نصي قابل للتنزيل، وقسم أسئلة وأجوبة محدود بالقواعد المتاحة.
- واجهة عربية/إنجليزية.

**حدود مهمة:** لا يُثبت عدم رصد مشكلة أن العقد متوافق قانونيًا. استخراج OCR والجداول قد يتضمن أخطاء. لا يتحقق التطبيق آليًا من جميع الاستثناءات أو مدة الخدمة أو مجموع الراتب والبدلات.

## كيف يعمل التحليل؟

1. يرفع المستخدم عقد PDF افتراضيًا.
2. يستخرج النظام النص؛ وإذا كانت الصفحة مصورة يحاول OCR.
3. يبحث عن عبارات وأرقام مرتبطة بالموضوعات الأربعة.
4. يطبق قواعد تحفظية؛ إذا كان النص غامضًا أو ناقصًا لا يصدر حكمًا جازمًا.
5. يعرض الملاحظة والتفسير والمرجع لمراجعة المستخدم.

**مثال:** فترة تجربة مقدارها 200 يوم تُعرض بوصفها **تعارضًا محتملًا** مع الإشارة إلى المادة 53، مع ضرورة مراجعة النص النظامي الساري والسياق.

## المراجع وRAG

النسخة الحالية **لا تطبق RAG كاملًا**. وهي تستخدم **فهرسًا مرجعيًا محليًا منتقى مسبقًا** لربط الموضوعات بأرقام المواد وروابط الجهات الرسمية؛ ولا تجلب النصوص النظامية مباشرة عند كل تحليل، ولا تتحقق آليًا من آخر التحديثات أو من سريان كل استثناء.

**خطة التطوير:** بناء قاعدة موثقة من المصادر السعودية الرسمية، مع بيانات تاريخ السريان والتعديل ونطاق التطبيق؛ استرجاع النصوص المرتبطة بالبند؛ التحقق من قابلية انطباقها؛ إظهار مقتطف المادة ورابطها وتاريخ التحقق؛ وإحالة الحالات الملتبسة إلى مراجعة بشرية.

**مصدر رسمي للتحقق اليدوي:** [وزارة الموارد البشرية والتنمية الاجتماعية](https://www.hrsd.gov.sa/) — ينبغي الرجوع إلى النسخة السارية من نظام العمل ولوائحه والقرارات ذات الصلة.

## الاختبارات المنفذة على عقود افتراضية

| الحالة | النتيجة المرصودة |
|---|---|
| PDF نصي يحتوي البنود الأربعة | استُخرج النص وعُرضت النتائج |
| PDF مصوّر بالعربية | محاولة OCR مع تحذير من الاعتماد الجازم على الأرقام |
| جدول راتب وبدلات | ظهرت بيانات الجدول في النص المستخرج، دون التحقق حسابيًا من الإجمالي |
| فترة تجربة 200 يوم | تعارض محتمل |
| إجازة سنوية 14 يومًا | تعارض محتمل |
| 10 ساعات يوميًا و6 أيام أسبوعيًا | تحتاج مراجعة، مع بيان 60 ساعة أسبوعيًا |
| ساعات عمل «حسب احتياجات الشركة» بلا تحديد | معلومات ناقصة |
| راتب «يحدد لاحقًا» بلا مبلغ | معلومات ناقصة |
| فترة تجربة 90 يومًا | لم يُرصد تجاوز للمدة |

هذه **اختبارات وظيفية محدودة** على مستندات اصطناعية، وليست دراسة دقة إحصائية أو تحققًا قانونيًا شاملًا. لم يُقَس بعد معدل الدقة/الاسترجاع على مجموعة اختبار مستقلة محكّمة.

## المقارنة مع الحلول الأخرى

توجد منصات تجارية مثل **Spellbook** و**LegalOn** تساعد في مراجعة العقود وتحديد المخاطر. يتميز **تركيز دقّق المقترح** بنطاق تعليمي ضيق: أربعة موضوعات في عقد العمل السعودي، وواجهة عربية/إنجليزية، وعرض رقم المرجع النظامي مع الملاحظة. لا يعني ذلك أن الحلول الأخرى تفتقر بالضرورة إلى دعم اللغة العربية أو القانون السعودي؛ يلزم بحث سوقي أوسع لإثبات أي تفوق تنافسي.

## الخصوصية

- لا تستخدم النسخة الحالية نموذج ذكاء اصطناعي خارجيًا لتحليل نص العقد.
- تتم معالجة الملفات على خادم الاستضافة الذي يشغّل Streamlit، لذلك **لا يُفترض أن المعالجة محلية على جهاز المستخدم**.
- لا توجد قاعدة بيانات مقصودة لتخزين العقود ضمن النموذج، لكن لا يمكن الجزم بسياسات سجلات الاستضافة أو الاحتفاظ بها دون مراجعتها.
- **استخدم عقودًا افتراضية فقط** عند التجربة والعرض؛ لا ترفع مستندات حقيقية تتضمن معلومات شخصية أو سرية.

## تشغيل المشروع محليًا

```bash
pip install streamlit pymupdf
streamlit run app.py
```

قد يتطلب OCR تثبيت مكونات OCR الإضافية المناسبة في بيئة التشغيل. راجع إعدادات نشر التطبيق وملفات المتطلبات في المستودع.

## حالة النشر والتسليم

- التطوير والاختبار يجريان حاليًا على الفرع `daqqiq-improvements` والرابط التجريبي.
- **لم يُعتمد الرابط الرسمي النهائي بعد**: يجب نقل التحديثات إلى `main` واختبار الموقع الرسمي قبل نشر رابط واحد للمشرف.
- استضافة Streamlit Community Cloud المجانية قد تدخل التطبيق في وضع السكون عند عدم الاستخدام. **لم تُحل مشكلة الإتاحة الدائمة بعد**؛ يلزم اختبار الاستضافة وخطة عرض احتياطية مثل فيديو توضيحي.

## التطوير المستقبلي

RAG موثق ومحدّث، تحسين قراءة الجداول وOCR، اختبارات محكّمة أوسع، تحققات أكثر للسياق والاستثناءات، وضوابط أقوى للخصوصية والاستضافة.
